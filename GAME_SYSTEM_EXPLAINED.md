```

```

### Step 2: Admin Adds Points
```
1. Admin verifies payment received
2. Admin logs into Admin Panel
3. Admin goes to "Users" tab
4. Admin finds the user
5. Admin clicks "Add Points"
6. Admin enters: 500 points (= 500 Birr)
7. Admin clicks "Confirm Add"
8. User receives 500 points instantly!
```

### Step 3: User Plays Games
```
User has 500 points
↓
User bets 10 points on Plinko
↓
If WIN (2x multiplier):
  - User wins 20 points
  - Balance: 500 - 10 + 20 = 510 points ✅
↓
If LOSE:
  - User loses 10 points
  - Balance: 500 - 10 = 490 points ❌
```

## 💸 Withdrawal Flow

### User Requests Withdrawal

**Requirements:**
- Minimum: 500 points
- 1 point = 1 Birr

**Process:**
1. User has 1000 points
2. User requests withdrawal of 500 points
3. Points deducted immediately: 1000 - 500 = 500 points
4. Withdrawal status: PENDING

**Admin Approves:**
1. Admin sees pending withdrawal in Admin Panel
2. Admin reviews: 500 points = 500 Birr
3. Admin clicks "Approve"
4. Admin sends 500 Birr to user (bank/mobile money)
5. Admin clicks "Mark as Paid"
6. Withdrawal complete! ✅

**If Admin Rejects:**
1. Admin clicks "Reject"
2. Points automatically refunded: 500 + 500 = 1000 points
3. User can play again or request new withdrawal
