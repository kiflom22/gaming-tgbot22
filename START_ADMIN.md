# 🚀 Start Using Admin Dashboard

## ⚡ Quick Start (3 Steps)

### 1️⃣ Clear Browser Data
Press **F12** → **Application** → **Local Storage** → **Clear All**

### 2️⃣ Login as Admin
- Username: `admin`
- Password: `admin123`

### 3️⃣ Click Admin Panel Button
Look for **🛡️ Admin Panel** in the lobby

---

## 🎯 Admin Features

### 👥 Manage Users
- Add points when users pay externally
- Suspend/activate accounts
- View user statistics

### 💸 Handle Withdrawals
- Approve withdrawal requests
- Process payment externally
- Mark as paid

### 🎮 Control Games
- Enable/disable games
- Set maintenance messages
- View game history

---

## 📊 Point System

1. User pays 500 Birr → Admin adds 500 points
2. User plays games with points
3. User wins/loses → Points increase/decrease
4. User requests withdrawal (min 500 points)
5. Admin approves → Processes payment → Marks paid

---

## ✅ Servers Running

- Backend: http://localhost:8000
- Frontend: http://localhost:3000 or 3001

---

## 🔧 If Problems

Run: `cd backend/scripts && python verify_admin.py`

Then clear browser data and login again.

**That's it! Clear localStorage, login, and start managing!**
